# OpenRevive plugin: проверка на BlackLion, 2026-10-15

Пакет находится в `plugins/openrevive`, основной скилл — `skills/legacy-mac`, самостоятельная команда — `bin/openrevive`. Он работает независимо от прежних прототипов в инфраструктурном репозитории. [Полное руководство](legacy-mac-plugin.md) содержит настройку и установку в агенты.

Приёмка: **6 выполнено, 0 невыполнено, 0 отменено**. Пять исполняемых проверок прошли на текущем коде; шестое условие — ручная сверка документации и изображений.

Проверено на MacBook4,1 с OS X 10.7.5 (11G63), Xcode 4.6.3 и SDK iOS 6.1. Подключение: `oz@blacklion.local` через SSH и существующий ключ. Пароль и приватный ключ в репозиторий не записывались. Помощник установлен в `~/Library/Application Support/OpenRevive`; установленная версия — 0.1.0.

Нативный AX-цикл обычно занимал около 0,3–0,5 секунды на запрос по этому Wi-Fi. Ввод короткой Unicode-строки занимал около 0,7 секунды; скриншот дополнительно ждёт перерисовку после пробуждения. Это наблюдения одного запуска, без обещания сетевой задержки.

Кодексовый standalone CLI на этой машине старее приложения и не понимает сохранённый `model_reasoning_effort = "max"`. Установщик временно переопределяет разбор этого параметра только для команд управления плагином. Пользовательская настройка осталась `max`; модельные запросы при установке и проверке не создавались.

Исходные прототипы и пользовательские приложения сохранены. Проверки создают только собственные probe-приложения, временные каталоги и build/logs внутри OpenRevive. Параллельно появившиеся `lab/**`, `GATES.md` и другие документы проекта к этой работе не относятся и не включаются в её коммит. Общий README сохраняет концепцию и оглавление DNS/CA-стенда; к ним добавлена ссылка на отдельное руководство по плагину.

## Что пока не подтверждено

Физический iPhone в текущем usbmuxd не перечисляется: список пуст. Поэтому pairing, подпись, установка и запуск на реальном телефоне не заявлены. Нужны зарядка/проверка кабеля и новое чтение фактических ProductType, ProductVersion и UDID. Текущая сборка armv7 подтверждает компиляцию, а USB-мост — транспорт.

Instruments UIAutomation по-прежнему имеет проблемы авторизации/сессии на BlackLion и иногда возвращает 0 при ошибке. Полноценное дерево UIKit и семантическое управление iOS через него не подтверждены. Рабочий маршрут Simulator — его окно, нативный ввод, скриншот и результат приложения. `/etc/authorization` не ослаблялся этим плагином.

Другие версии macOS, Retina/несколько экранов, заблокированный экран и loginwindow не прошли live-проверку. Установщик намеренно ограничен старой системой 10.7.3–10.8.x; перенос на современный TCC требует другого механизма разрешений.
